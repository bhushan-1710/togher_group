# Togher Group Website Redesign

**Project:** Premium website redesign / demo
**Client:** Togher Group
**Primary source:** https://www.toghergroup.com/
**Status:** Documentation / pre-development
**Source of truth:** `SOURCE_OF_TRUTH.md`

> This document set is intended to guide a production-quality redesign. Verified company facts are separated from design proposals. Any fact that could not be verified is explicitly marked `[VERIFY]`.

## Global Components
### Header
Purpose: navigation and conversion. Desktop: logo + nav + CTA. Mobile: logo + menu + contact action. Animation: 150–250ms state transitions. Accessibility: semantic `<header>`, `<nav>`, keyboard menu control.

### Footer
Purpose: site-wide discovery and trust. Include approved office/contact information, primary routes and legal links.

### Page Transition
Subtle opacity/clip transition; never block interaction.

## Hero
Large headline, concise supporting copy, one primary CTA, optional secondary link and high-quality media. Mobile stacks type before media where appropriate.

## Section Header
Eyebrow + large heading + optional short body. Keep section rhythm consistent.

## Split Content
40/60 or 50/50 editorial grid. Mobile becomes vertical with deliberate order.

## Project/Experience Card
Use only verified projects. Image-led, minimal metadata, hover crop movement.

## Service Feature
Prefer editorial rows or large numbered sections over a wall of cards.

## Stat Block
Only for verified statistics with source/date. Otherwise do not render.

## Testimonial
Only verified client attribution and approved quote.

## Team Card
Portrait + name + role only when approved.

## Article Card
Use for verified insights/news.

## Accordion
Use only where progressive disclosure improves scanning; keyboard accessible.

## Filter
Only if vacancies/insights justify it.

## Form
Clear labels, validation, privacy note, success/error states.

## CTA Block
Strong typographic close with one primary action.
