# Togher Group Website Redesign

**Project:** Premium website redesign / demo
**Client:** Togher Group
**Primary source:** https://www.toghergroup.com/
**Status:** Documentation / pre-development
**Source of truth:** `SOURCE_OF_TRUTH.md`

> This document set is intended to guide a production-quality redesign. Verified company facts are separated from design proposals. Any fact that could not be verified is explicitly marked `[VERIFY]`.

## 1. Potential Client → Enquiry
**Entry:** Home / service page
**Intent:** Understand capability and engage.
**Steps:** Hero → service → proof/process → CTA → enquiry form → success.
**Decision:** Which service?
**CTA:** Discuss Your Requirement.
**Outcome:** Qualified enquiry.

## 2. Contractor/Partner → Contact
Entry: About / Services / Contact.
Intent: establish relationship.
Steps: understand group → identify relevant capability → contact.

## 3. Candidate → Careers
Entry: Home / Careers CTA / organic search.
Intent: find role or register.
Steps: Candidates → Vacancies → role → apply / submit CV.
The current site already supports CV upload and job-alert subscription. citeturn0search1

## 4. Visitor → Service Discovery
Entry: Home.
Intent: understand what Togher offers.
Steps: Hero → capabilities → service detail → contact.

## 5. Visitor → Project/Experience Discovery
Entry: Home or relevant sector page.
Intent: verify practical experience.
Steps: experience → detail → related capability → enquiry.
**Dependency:** verified project content required.

## 6. Visitor → Company Credibility
Entry: Home / About.
Intent: determine whether Togher is credible.
Steps: group story → leadership → values → markets → services → contact.

## 7. Mobile User → Enquiry
Entry: any page.
Intent: contact quickly.
Requirement: sticky but unobtrusive contact action, short form, click-to-call/email where approved.
