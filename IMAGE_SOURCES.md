# TOGHER GROUP — IMAGE ASSET & SOURCING LEDGER
**Project Reference:** TG-2025 // ASSET-MANIFEST  
**Documentation File:** `IMAGE_SOURCES.md`  
**Purpose:** Comprehensive tracking ledger of all external structural stock exhibits placed across the Togher Group web application. These assets serve as an interim visual baseline until proprietary Togher Group project, site, and team photography becomes available.  
**Curation Standard:** Non-generic, high-contrast, graphic architectural & engineering material details (raw concrete, structural steel, rebar reinforcement cages, CAD drawings, tower cranes). No generic stock tropes (no hi-vis handshakes, no smiling models, no visible corporate branding/logos).

## How to Replace Images Later
To swap any exhibit across the application with proprietary photography:
1. Save the new image in `public/images/` using the same filename, OR update the `src` / `imageSrc` property in the respective page client component (`AboutClient.tsx`, `ServicesClient.tsx`, `ClientsClient.tsx`, `CandidatesClient.tsx`, `VacanciesClient.tsx`, `ContactClient.tsx`).
2. Update this ledger file (`IMAGE_SOURCES.md`) with the new photographer credit and rights clearance.
3. The component's `<ExhibitFrame />` and `<DossierCard />` will automatically apply the desaturated high-contrast architectural processing, hard-edged non-rounded crop, and mono metadata caption bar.
